# Airport Check-in and Passenger History Management System

## Project Overview

The Airport Check-in and Passenger History Management System is a web-based application developed using HTML, CSS, and JavaScript. It helps manage passenger registration, waiting queues, check-in processing, and passenger history through a simple and user-friendly dashboard.

## Features

- **Passenger Registration:** Add new passenger details.
- **Passenger Dashboard:** View passenger statistics and recent check-ins.
- **FIFO Queue Management:** Process passengers in First In, First Out order.
- **Check-in Processing:** Check in the passenger at the front of the waiting queue.
- **Passenger History:** View previous check-in records, with the latest records displayed first.
- **Search Functionality:** Search passenger records easily.
- **CSV Export:** Export passenger records for external use.
- **Local Storage:** Save records in the browser so they remain available after refreshing the page.
- **Responsive Design:** Access the dashboard on desktops, tablets, and mobile devices.

## Technologies Used

- **HTML5** – Structures the web pages.
- **CSS3** – Provides styling and responsive layouts
